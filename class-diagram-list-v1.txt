15) Are these APIs free?
- These endpoints are your own application APIs (no third-party API fees for the endpoint itself).
- Payment processing is manual (buyer uploads `ProofImageId`), so there is no external payment-gateway API integration in this code.

16) Email service used
- `EmailHelper` uses SMTP (`System.Net.Mail.SmtpClient`) to send emails.
- `Web.config` is configured for Gmail SMTP: host `smtp.gmail.com`, port `587`, SSL enabled (`SmtpEnableSsl=true`).
- Credentials and sender name come from `Web.config` appSettings keys: `SmtpUser`, `SmtpPassword`, `FromEmail`, `FromDisplayName`.
